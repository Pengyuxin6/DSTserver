# 饥荒联机版 (Don't Starve Together) 专用服务器

## 环境信息

| 项目 | 说明 |
|------|------|
| 操作系统 | Debian GNU/Linux 13 (trixie) x86_64 |
| 运行用户 | `steam` |
| 用户主目录 | `/home/steam` |
| SteamCMD 目录 | `/home/steam/steamcmd` |
| DST 服务端目录 | `/home/steam/dst_server` |
| 集群存档目录 | `/home/steam/.klei/DoNotStarveTogether/MyDediServer` |
| 集群名称 | `MyDediServer` |

### 端口清单

| 端口 | 协议 | 用途 | 是否对外开放 |
|------|------|------|-------------|
| 11000 | UDP + TCP | 地面世界（Master）游戏端口 | ✅ 是 |
| 11001 | UDP + TCP | 洞穴世界（Caves）游戏端口 | ✅ 是 |
| 27018 | UDP | 地面 Steam 主服务器端口 | ✅ 是 |
| 27019 | UDP | 洞穴 Steam 主服务器端口 | ✅ 是 |
| 8768 | UDP | 地面 Steam 认证端口 | ✅ 是 |
| 8769 | UDP | 洞穴 Steam 认证端口 | ✅ 是 |
| 10889 | TCP | 地面与洞穴分片内部通信 | ❌ 否（仅 127.0.0.1） |

> **云安全组**也需要在阿里云控制台添加对应的入站规则，TCP+UDP 都放最省心。

### Cluster Token

| 项目 | 值 |
|------|-----|
| Token | `<在此粘贴你的 Klei Token>` |
| Token 文件 | `/home/steam/.klei/DoNotStarveTogether/MyDediServer/cluster_token.txt` |

> ⚠️ Token 等同于服务器身份凭证，不要泄露给他人。

## 快速开始（开服步骤）

### 第 1 步：填写 Cluster Token（必须！）

这是服务器能注册到 Klei 官网的唯一凭证，**不填无法开服**。

1. 在你本地电脑上打开 Steam 版《饥荒联机版》
2. 进入游戏首页，点击 **"账户"**（或个人资料按钮）
3. 浏览器会打开 Klei 账号页面
4. 找到 **"Generate Server Token"**（生成服务器令牌）
5. 复制生成的 token 字符串
6. 登录服务器，写入 token 文件：

```bash
su - steam
nano ~/.klei/DoNotStarveTogether/MyDediServer/cluster_token.txt
```

把 token 粘贴进去（覆盖掉里面的说明文字），保存退出。

### 第 2 步：修改房间名和密码（可选）

```bash
su - steam
nano ~/.klei/DoNotStarveTogether/MyDediServer/cluster.ini
```

关键配置项：

```ini
[NETWORK]
cluster_name = 我的饥荒服务器          # 在游戏服务器列表中显示的名称
cluster_description = 欢迎来玩          # 服务器描述
cluster_password =                    # 留空=无密码，填了=进服需要密码

[GAMEPLAY]
game_mode = survival                  # 游戏模式: survival / endless / wilderness
max_players = 6                       # 最大人数
pvp = false                           # 是否开启 PVP
```

### 第 3 步：开放端口（防火墙 + 云安全组）

服务器需要放行以下端口（TCP + UDP 都放）：

| 端口 | 用途 |
|------|------|
| 10999-11000 | 地面世界通信 |
| 11000-11001 | 洞穴世界通信 |
| 27018-27019 | Steam 主服务器端口 |
| 8768-8769 | Steam 认证端口 |

如果系统启用了 UFW 防火墙：

```bash
ufw allow 11000:11001/udp
ufw allow 11000:11001/tcp
ufw allow 27018:27019/udp
ufw allow 27018:27019/tcp
ufw allow 8768:8769/udp
ufw allow 8768:8769/tcp
ufw reload
```

> **云服务器用户注意**：除了系统防火墙，还需要在云厂商控制台（阿里云/腾讯云/AWS 等）的"安全组/防火墙/入站规则"中放行以上端口。

### 第 4 步：启动服务器

```bash
su - steam
~/start_dst.sh
```

脚本会在 screen 会话中分别启动地面世界和洞穴世界。

### 第 5 步：验证服务器状态

查看地面世界控制台：

```bash
screen -r dst_master
```

看到类似 `Online Server Started on port: 11000` 表示启动成功。

**退出 screen（不关服务器）**：按 `Ctrl+A`，然后按 `D`。

查看洞穴世界：

```bash
screen -r dst_caves
```

看到 `secondary shard is now ready` 表示洞穴也已就绪。

### 第 6 步：在游戏中加入

1. 打开饥荒联机版
2. 点击 "Play" → "Browse Games"（浏览服务器）
3. 搜索你在 `cluster_name` 中设置的房间名
4. 输入密码（如果设了的话），加入

## 配置文件详解

### cluster.ini — 集群总配置

路径：`~/.klei/DoNotStarveTogether/MyDediServer/cluster.ini`

| 配置项 | 说明 | 示例值 |
|--------|------|--------|
| `game_mode` | 游戏模式 | `survival` / `endless` / `wilderness` |
| `max_players` | 最大玩家数 | `6` |
| `pvp` | 是否 PVP | `true` / `false` |
| `pause_when_empty` | 无人时是否暂停 | `false`（建议关闭） |
| `cluster_name` | 服务器名称 | `My DST Server` |
| `cluster_description` | 服务器描述 | `A dedicated server` |
| `cluster_password` | 服务器密码 | 空 = 无密码 |
| `console_enabled` | 是否启用控制台 | `true` |
| `shard_enabled` | 启用分片（地面+洞穴） | `true` |
| `bind_ip` | 分片绑定 IP | `127.0.0.1` |
| `master_ip` | 主世界 IP | `127.0.0.1` |
| `master_port` | 分片通信端口 | `10889` |
| `cluster_key` | 分片通信密钥 | 自定义字符串 |

### Master/server.ini — 地面世界配置

| 配置项 | 说明 |
|--------|------|
| `server_port` | 地面世界端口（默认 11000） |
| `is_master` | 是否为主世界（`true`） |
| `master_server_port` | Steam 主服务器端口（27018） |
| `authentication_port` | Steam 认证端口（8768） |

### Caves/server.ini — 洞穴世界配置

| 配置项 | 说明 |
|--------|------|
| `server_port` | 洞穴世界端口（默认 11001） |
| `is_master` | 是否为主世界（`false`） |
| `name` | 分片名称（`Caves`） |
| `master_server_port` | Steam 主服务器端口（27019） |
| `authentication_port` | Steam 认证端口（8769） |

## 安装 Mod（可选）

### 方法 1：从客户端复制配置

1. 在本地饥荒客户端中创建游戏，订阅并启用你想要的 Mod
2. 找到客户端的 Mod 配置文件 `modoverrides.lua`
   - Windows 路径通常在：`Documents\Klei\DoNotStarveTogether\你的存档\Master\modoverrides.lua`
3. 将 `modoverrides.lua` 复制到服务器的：
   ```
   ~/.klei/DoNotStarveTogether/MyDediServer/Master/modoverrides.lua
   ~/.klei/DoNotStarveTogether/MyDediServer/Caves/modoverrides.lua
   ```
4. 重启服务器，服务端会自动从 Steam Workshop 下载 Mod

### 方法 2：手动添加

在 `modoverrides.lua` 中添加：

```lua
return {
    ["workshop-378160973"] = { enabled = true },  -- Global Positions
    ["workshop-1207439837"] = { enabled = true },  -- Combined Status
    -- 添加更多 Mod...
}
```

## 常见问题

### Q: 能看到服务器但连不上 / 进不去

1. 检查 `cluster_token.txt` 是否已填写正确的 Token
2. 检查防火墙端口是否放行（包括云安全组）
3. 确保 `pause_when_empty = false`
4. 查看 screen 控制台有无报错：`screen -r dst_master`

### Q: 洞穴连不上地面

1. 确认 `cluster.ini` 中 `shard_enabled = true`
2. 确认 `master_ip = 127.0.0.1`、`master_port = 10889`
3. 确认地面和洞穴的 `cluster_key` 一致
4. 查看日志中是否有 `Shard server started on port: 10889`

### Q: libcurl-gnutls.so.4 找不到

```bash
# 创建软链接解决
ln -s /usr/lib/x86_64-linux-gnu/libcurl-gnutls.so.4 /home/steam/dst_server/bin64/libcurl-gnutls.so.4
```

### Q: SteamCMD 下载失败 / 速度慢

SteamCMD 下载依赖网络，如果服务器在国内可能较慢。可以多次重试或配置代理。

## Web 管理面板（dst_panel）

基于 Bun + TypeScript 的 Web 管理面板，复刻 Windows 桌面管理工具的全部功能：基本设置、编辑世界（leveldataoverride.lua）、mod 设置（预览图/名称自动从 Steam 创意工坊 API 获取）、服务器管理、控制台、玩家记录、聊天记录、帮助。

| 项目 | 值 |
|------|-----|
| 代码目录 | `/home/steam/dst_panel/` |
| 运行方式 | systemd 服务 `dst-panel.service`（以 steam 用户运行） |
| 监听地址 | `127.0.0.1:5322`（仅本机，不直接对外） |
| 外部访问 | nginx 80 端口映射：`http://<服务器IP或域名>/dst/`（80 站点首页菜单已有入口"饥荒服务器管理"） |
| 登录密码 | `/home/steam/dst_panel/.panel_password`（mode 600，与 steam 用户密码一致） |
| 模组缓存 | `/home/steam/dst_panel/mod_cache.json`（Steam API 结果，6 小时 TTL） |
| 面板配置 | `/home/steam/dst_panel/panel_config.json`（当前集群、在线/离线模式、自动重启、自动公告） |

### 常用命令

```bash
systemctl status dst-panel      # 查看面板状态
systemctl restart dst-panel     # 重启面板
journalctl -u dst-panel -f      # 查看面板日志
```

### nginx 映射位置

`/etc/nginx/sites-enabled/` 中的 80 端口站点配置（默认站点与站点域名 server 块）均已加入 `location /dst/` 反代到 `127.0.0.1:5322`。80 站点首页菜单已加入口。

### 模组加载两层机制（详见《饥荒服务器模组迁移指南》）

1. **模组文件**：`dedicated_server_mods_setup.lua` 中 `ServerModSetup("ID")`，服务器启动时自动下载；或由面板"mod下载与更新"页直接下载。**注意**：模组统一存放在全局目录 `/home/steam/dst_mods/<id>/`（不按存档区分），各存档分片通过符号链接使用；启用/配置按存档写在 modoverrides.lua。详见 `dst_panel/docs/模组管理.md`。
2. **启用配置**：`Master/` 和 `Caves/` 下的 `modoverrides.lua`（面板"保存所选"会同时写两个分片）。

### 端口开放提醒

面板只需 **80 端口**（已开放）；游戏端口按上文端口清单放行即可；`5322` 仅监听 127.0.0.1，无需对外开放。

> 注意：面板实际监听 `127.0.0.1:5323`（nginx `/dst/` 已指向该端口）。5322 端口被弃用。
