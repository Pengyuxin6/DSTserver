# 饥荒服务器模组管理文档

> 本文档说明本服务器模组的存储结构、加载机制与面板操作方式。面板地址：`http://<服务器>/dst/` → 「mod设置」。

---

## 一、模组存储结构（全局统一存储）

所有模组集中存放在**全局独立文件夹** `/home/steam/dst_mods/`，每个模组一个以创意工坊 ID 命名的子文件夹。**不绑定任何存档**，全机所有存档共用同一份，下载也只下载一次。

```
/home/steam/
├── dst_mods/                              # ★ 全局模组文件夹（唯一实体目录）
│   ├── 1185229307/                        # 模组 ID 命名的子文件夹
│   ├── 1909182187/
│   └── ...
└── dst_server/ugc_mods/
    └── <存档名>/                           # 每个存档一份链接，不存实体
        ├── Master/content/322330 -> /home/steam/dst_mods   # 符号链接
        └── Caves/content/322330  -> /home/steam/dst_mods   # 符号链接
```

- **存储统一**：模组文件只有 `/home/steam/dst_mods/<id>/` 一份实体，与存档无关。
- **应用分文件夹**：每个模组独立 ID 子文件夹（`modinfo.lua`、`modmain.lua`、资源文件）。
- **配置按存档**：启用与配置才按存档区分，写在各存档 `Master/`、`Caves/` 的 `modoverrides.lua`。
- **下载统一**：面板下载（CDN/steamcmd）只落到全局目录一次；面板会自动建立并维护上述符号链接（含从旧位置迁移），无需手工干预。
- **旧位置兼容**：`mods/workshop-<id>/` 与老版 `ugc_mods/<存档>/shared/` 的内容会被面板自动迁移进全局目录。

## 二、模组生效的两层机制（缺一不可）

```
第一层：模组文件存在        → shared/322330/<id>/ （下载）
第二层：存档中启用并配置     → <存档>/Master/modoverrides.lua + <存档>/Caves/modoverrides.lua
```

| 操作 | 面板入口 | 实际写入 |
|------|---------|---------|
| 添加模组（仅登记） | mod下载与更新 → 搜索/批量添加 | `dedicated_server_mods_setup.lua` 增加 `ServerModSetup("ID")` |
| 下载模组 | 批量下载 / 立即下载 / 更新全部 | 下载到全局目录 `/home/steam/dst_mods/<id>/`（CDN 直链优先，失败回退 steamcmd，最多 3 个并行） |
| 启用模组 | 本地Mod → 勾选 → 保存所选 | 两个分片的 `modoverrides.lua` 写入 `["workshop-ID"] enabled=true`（同时写入 setup 清单） |
| 配置模组 | 本地Mod → 点模组行 → 右侧配置项 → 保存修改 | 两个分片 `modoverrides.lua` 的 `configuration_options` |
| 删除模组 | （勾选状态取消 + 保存所选 = 停用）；文件层面删除在模组详情中 | 删除 `shared/322330/<id>/` 与 setup 清单行 |

> 所有改动**重启服务器后生效**。

## 三、面板功能说明

### 本地Mod 页

- 列表合并三个来源：已下载文件、setup 清单、modoverrides 启用记录。
- 每行显示：预览图、名称（Steam 创意工坊 API + 本地 modinfo.lua 双重来源）、版本/更新日期、标签（仅客户端/全员需要）、状态（已下载/未下载/已启用）。
- **红色行** = 已启用但未下载，点「下载缺失模组」一键补齐。
- 「刷新」会重新请求 Steam API 补全名称与预览图（结果缓存 6 小时）。

### mod下载与更新 页

- **按名称搜索**：抓取 Steam 创意工坊结果，带预览图，可直接「添加」或「下载」。
- **按 ID 批量操作**：文本框每行一个或逗号分隔，支持批量添加/批量下载。
- **下载任务**：最多 3 个并行，实时进度条（已下载/总大小），点「日志」查看详情。

## 四、常见问题

### Q1：勾选了模组但游戏里没有生效

按顺序检查：
1. `/home/steam/dst_mods/<id>/modinfo.lua` 是否存在（不存在 → 点「下载缺失模组」）；
2. `Master/modoverrides.lua` 和 `Caves/modoverrides.lua` 里是否都有该模组且 `enabled = true`；
3. 改完后是否**重启了服务器**。

### Q2：玩家进服提示缺少模组

该模组 `modinfo.lua` 中 `all_clients_require_mod = true`，玩家需在创意工坊订阅同名模组。

### Q3：mods 目录下的 workshop- 文件夹消失了

新版服务端（UGC 系统）启动时会把 `mods/workshop-<id>/` 迁移到 `ugc_mods/<存档>/<分片>/content/322330/<id>/`，本面板已把它们统一链接到全局目录 `/home/steam/dst_mods/`。**这是正常迁移，不是丢失。**

### Q4：下载失败

- 「无 CDN 直链，转 steamcmd」属于正常回退（新上传的模组没有直链）；
- steamcmd 失败常见原因：外网不通、Steam 限流，可稍后重试或重启服务器让服务端自己下载。

### Q5：模组配置项改了没效果

配置保存在 `modoverrides.lua` 的 `configuration_options`，需**重启服务器**生效；部分模组自身有版本兼容问题，看 `Master/server_log.txt` 中该模组的报错。

## 六、大型地图模组（海难 / 哈姆雷特 / 三合一等）

这类模组（如 Shipwrecked Together）会**替换整个世界的生成规则**，原版的世界设置项不再完全适用。面板「编辑世界」页会自动检测已启用的此类模组，并额外显示「模组世界设置」卡片：

- **关卡预设**：从模组脚本解析出的预设列表（如 SHIPWRECKED_SURVIVAL_TOGETHER=生存、VOLCANO_LEVEL=火山），点「应用预设」写入 `leveldataoverride.lua` 的 `worldgen_preset`/`settings_preset`，并自动合并预设自带参数（如 `start_location = "islands"`）。
- **模组设置项**：从模组 `customize_patch.lua` 解析出的专属世界选项（如海难的虎鲨、海妖、剑鱼等，含适用世界 shipwrecked/volcanolevel 标注），操作方式与原版设置项一致：点行选值，点上方「保存」统一写入。
- 当前生效的预设显示在「设置项」卡片标题栏。
- 改动需**重新生成世界**（控制台 → 重新生成世界，或新建存档）才会完整体现。

### 补充说明（世界类型 vs 模式难度 / 模组物品）

- **世界类型与原版互斥**：海难（SHIPWRECKED_*）替换主世界、火山（VOLCANO_LEVEL）替换洞穴——选了模组世界就不再是原版世界。面板「世界类型」下拉可一键在 原版/海难/火山 间切换（写 `worldgen_preset`）。
- **模式难度独立设置**：生存/轻松/无尽/荒野/暗无天日是游戏模式（写 `settings_preset`），与世界类型互不干扰。
- **设置项中文名**：优先取中文语言包模组（Chinese Language Pack）的翻译，其次模组自带字符串与原版物品表，单复数自动匹配。
- **控制台「模组物品」分类**：自动扫描已启用模组 `scripts/prefabs/` 新增的物品（当前海难模组识别出 249 个），与原版物品一样可搜索、给予或放到脚下。
